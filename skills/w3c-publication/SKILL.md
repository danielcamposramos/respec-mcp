# Publication and transition packages

Select the actual track and transition in the current W3C guide before assembling the package. Identify the exact document revision, status, group decision, change history, review dispositions and implementation evidence applicable to that transition. Keep unmet requirements visible.

Use ReSpec or the repository's generator for the document, then the relevant Pubrules profile and other required publication checks. ReSpec diagnostics are not a substitute for Pubrules. Echidna performs publication, so use it only within existing publication authorization and required W3C process decisions. Report each check and decision separately; never label a local green result as institutional approval.

## Shared guidance and tools

Read [Shared editorial principles](../../docs/EDITORIAL_PRINCIPLES.md) for native-language collaboration and the boundaries of automated checks. Use only tools applicable to this document: W3C transition selector, Pubrules / Specberus, Echidna, W3C Link Checker.
