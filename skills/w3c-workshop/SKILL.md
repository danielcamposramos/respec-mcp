# Workshop calls, programs and reports

Use the current workshop guide to establish purpose, audience and the intended outcome. Keep participation instructions, dates, accessibility arrangements and the program consistent. In the report, connect conclusions to the actual sessions and contributions, distinguishing consensus, differing views and proposed follow-up.

Use the established workshop pages and templates instead of forcing them into a specification profile. Check links and accessible markup with the appropriate web tools. Announcing a workshop, promising participation or publishing conclusions requires the applicable authorization; drafting these materials does not establish endorsement by W3C or by organizations named in a discussion.

## Shared guidance and tools

Read [Shared editorial principles](../../docs/EDITORIAL_PRINCIPLES.md) for native-language collaboration and the boundaries of automated checks. Use only tools applicable to this document: W3C workshop guidance, HTML and accessibility checks.
