# Security and privacy self-reviews

Read the current questionnaire against a specific design revision. Map data exposure, persistence, permissions, origin boundaries and misuse to concrete design behavior. Record an evidence-backed answer, an explained non-applicability or an open question; avoid generic assurances of safety.

Use the answers to write narrative Security Considerations and Privacy Considerations, rather than pasting a questionnaire as the entire discussion. Preserve residual risks and uncertainty. ReSpec can check whether sections exist, not whether a threat model is adequate. Keep a separate record of questions, design changes and review feedback for the appropriate human reviewers.

## Shared guidance and tools
