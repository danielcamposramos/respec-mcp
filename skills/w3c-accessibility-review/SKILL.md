# Accessibility self-reviews

Use the current FAST checklist linked from W3C's review guide. Relate user needs to the actual feature and its fallback behavior; distinguish accessibility of the document from accessibility of the technology it describes. Identify reliance on vision, hearing, movement or other input capabilities and explain equivalent ways to participate where applicable.

Record supporting design decisions, known gaps and questions for APA. Use semantic markup and alternatives for explanatory visuals. Automated markup or section checks do not establish accessibility conformance or replace user and assistive-technology evaluation. Prepare the review request with links to the self-review and relevant revision.

## Shared guidance and tools

Read [Shared editorial principles](../../docs/EDITORIAL_PRINCIPLES.md) for native-language collaboration and the boundaries of automated checks. Use only tools applicable to this document: FAST checklist, APA review request, WAI evaluation resources.
