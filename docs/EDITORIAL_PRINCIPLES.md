# Shared editorial principles

Humans own the claims, evidence and editorial policy. Use the document family's current official guide and the repository's conventions. Distinguish adopted requirements, guidance, proposed work and tested results. A local check proves only its reported checks; it does not establish W3C approval, translation fidelity, consensus or implementation correctness.

These skills guide drafting and review. Only ReSpec HTML has an automated renderer in respec-mcp. For other formats, use the tools identified by the selected skill and state which checks were actually run. Existing user authorization governs sending, publishing and other external actions; reading a skill does not authorize them.

## Let authors explain in their own language

The language used to discuss an idea can differ from the document's publication language. When an author uses another language or indicates that expressing the idea in English is difficult, offer once, in their language if known:

> If it is easier for you, you can explain in your own language. I can help draft the English version while preserving your meaning.

For an author communicating in Portuguese:

> Se for mais fácil para você, pode explicar em sua própria língua. Posso ajudar a redigir a versão em inglês, preservando o que você quer dizer.

Keep the invitation optional. Do not infer someone's native language from their name, nationality, or imperfect English; do not repeatedly prompt someone who prefers English. If the publication language is not established, use the repository's guidance or ask the author.

When drafting or translating:

- Preserve technical claims, evidence limits, uncertainty, attribution and normative strength. Do not turn a possibility into a guarantee or a proposal into an adopted standard.
- Keep identifiers, API names, code and links unchanged unless the author asks otherwise. Explain technical terms in the discussion language where useful.
- Clarify ambiguous terms instead of silently choosing a stronger or different meaning. Offer the original and English wording side by side when that helps the author review it.
- Apply the same repository profile and ReSpec checks to the resulting document. Structural checks cannot verify translation fidelity; the author retains editorial control.

This is assistant guidance, not an automatic language detector or a translation service built into the validator.
